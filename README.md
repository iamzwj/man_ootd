# 国内男性氛围摄影

仅发现国内公开网站与国内平台作品，男性主体、成年、穿衣，排除裸体、赤膊、内衣和泳装。国内来源通过页面域名白名单校验，不推断人物国籍。

ELLEMEN 公开摄影组图、360 图片搜索、必应国内站点搜索、图虫与堆糖持续按真实搜索页推进。新候选下载到内存，CLIP 比较成年男性穿衣肖像与女性、裸体、赤膊、内衣、儿童、插画等负例，符合者标记 automated-screened，不冒充人工审核。自动判断不能保证零误判；移除操作保存在当前设备。

每次下滑继续发现新图，搜索游标始终递增；换一批保留搜索进度，新图返回后替换当前视图，浏览指纹去重，不循环末页填充。不保证来源无限、每页有新结果或平台永久可访问；遇到空页按递增延时自动推进下一搜索页；离开底部或标签页隐藏时停止自动请求。请求携带已浏览/已返回图片 ID，后台从当前合格图库中取未读图片，避免异步晚到图片被页码切片跳过。

旧海外图库不进入本版推荐，缓存命名空间升级。服务器仅持久化 URL 和筛选元数据，最多 2000 条运行缓存；浏览器图片缓存上限 80。

运行：`PORT=8794 python3 server.py`。视觉模型依赖见 `deploy/prepare_vision.py`。
