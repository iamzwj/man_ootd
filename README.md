# OOTD · 男性氛围摄影

https://ootd.17design.fun

仅展示男性氛围摄影。移除穿搭频道，默认全部推荐；提供电影人像、黑白情绪及八种生活场景。

## 发现与展示

- 360 图片及必应图片：跨站发现原帖、摄影师网站、博客、抖音图文、Pinterest 和图库。搜索引擎是发现渠道，卡片来源保留真实站点；这不代表已接通各站官方接口。
- Flickr：公开摄影作品搜索，使用真实页码并保留作者、原帖和许可代码。
- 堆糖、图虫：国内公开搜索接口补充，失败互相隔离。
- `photo-catalog.json`：实际读取图片并通过视觉筛选的起始图库，只保存元数据，不保存照片文件。在线结果写入 `OOTD_CATALOG_PATH`，最多保留 2000 条，重启后恢复。
- 浏览器按页展示已验证图库，同时后台搜索下一批。单个来源失败不清空已验证照片；没有新匹配时不重复填充。公开搜索可能限流，不能保证无限供图或每张符合审美。
- 视觉筛选针对真人男性、表现性光影，排除女性、插画、商品和拼图等；仍有误判可能。跨站图片读取拒绝内网、私有地址和非 HTTPS。内容指纹用于跨地址去重。
- 收藏与浏览记录保留在当前浏览器；本机最多缓存 80 张图片。版权归原作者，查看原帖确认使用条件。

## 运行与验证

`OOTD_VISION_ROOT=/path/to/model python3 server.py`，访问 `http://127.0.0.1:8794`。

`node --test tests/feed.test.mjs`；`python3 -m unittest discover -s tests -p test_server.py`。

GitHub Actions 推送主分支后部署，验证摄影 API。systemd 使用独立 `ootd-photo` 状态目录保存元数据，不保存照片；每次发布同步更新视觉提示词向量。

## 人物形象与精选门槛 v4

以人物形象有吸引力、五官上镜、男模或时尚肖像质感为优先，再检查光线、构图与情绪。自动模型只做初筛，不作为客观颜值判断。只有 `reviewed: true` 且 `aestheticVersion: male-editorial-v4` 的照片可以发布。

旧图库和服务器历史推荐不再绕过本次审核；在线搜图存入候选池，不直接进入前台。浏览器推荐缓存升级，个人收藏保留。精选浏览完会明确提示，审核新图后继续补充，不用普通男性照片凑数量。


## 摄影师来源库（2026-10-22）

本版核查 342 个摄影师候选，逐图选择 100 位摄影师的 140 张男性肖像。计数单位是独立摄影师，合作者组合按一个来源计；对应 26 个域名，不声称有 100 个独立域名。

- 17 个摄影师个人官网、42 个官方代理个人作品集、41 个公开署名摄影系列；后者同时保留原作者主页。
- `photographer-sources.json` 是已选来源目录，`photo-catalog.json` 是逐图审批清单。来源目录的照片数由清单生成。
- `data/photographer-source-audit.json` 保存候选网址、访问状态和选入数量。访问成功不等于符合审美；只发布看过的具体照片，不整站放行。
- `GET /api/sources` 返回目录；`GET /api/discover?source=<摄影师姓名>` 从完整图库按作者分页。公开作品页与原作者主页分别提供，署名以主摄影师为准。
- 本版是首批精选快照。在线搜索仍只进入候选池，未审阅的新图不自动发布；不承诺无限结果或自动全量同步外部网站。
- 照片从公开原始地址加载，服务器不保存图片文件。新增缓存版本隔离旧版选图，保留用户收藏。

验证：100 个来源身份唯一，140 张图片指纹唯一，来源照片数与图库一致；作者筛选支持全量分页，末页停止，不重复填充。
